# Hospital Patient Analysis

## Aim
To analyze hospital patient age, admission duration, and billing information using R programming.

## Description
This project uses sample patient data to calculate average patient age, average admission days, total hospital revenue, and the patient with the highest bill.

## Technologies Used
- R Programming
- Data Frames
- Basic Statistical Functions

## Features
- Displays patient information
- Calculates average patient age
- Calculates average admission duration
- Calculates total hospital revenue
- Finds the highest bill

## How to Run
1. Open `09_Hospital_Patient_Analysis.R`.
2. Run the program in RStudio or VS Code.
3. View the results in the console.

## Result
The program successfully analyzes the sample hospital patient data.
